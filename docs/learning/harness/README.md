# Dossier harness/

Ce dossier contient les notes et référentiels de sources spécifiques à chaque
harness IA utilisé sur ce projet.

**Règle d'organisation** : un fichier par écosystème.

| Fichier | Contenu |
| --- | --- |
| `anthropic.md` | Sources de référence pour l'écosystème Anthropic (Claude Code, API) |
| `anthropic-notes.md` | Observations et comportements spécifiques à Claude Code |

Un fichier pour l'écosystème du second harness actif pourra s'ajouter ici
quand ces notes auront été constituées.

Ces documents sont les seuls de `docs/` qui peuvent légitimement nommer
un outil spécifique — c'est leur objet même.
